# Client logos

Put official logo files here (SVG or PNG with a transparent background works best),
then set the `logo` field for that client in `assets/data.js`, for example:

```js
{ name: "Toyota Indonesia", sector: "Automotive", logo: "assets/clients/toyota.svg" },
```

Use logos from each company's official press or brand kit, and check that you're
allowed to show them. Clients without a logo are shown as a text wordmark.
Logos show in greyscale and switch to full colour on hover.
