# Working rules

Two portfolio sites, picked by the tag in the request:

| Tag | Site | Repository and folder | Live address |
|---|---|---|---|
| `-Ivan` or `-Rayhan` | Ivan's portfolio (Muhammad Rayhan Ravandika) | `ivanrayhannn/rayhan_ravandika_portofolio`, repository root, branch `claude/optimistic-faraday-6kxzio` | https://ivanrayhannn.github.io/rayhan_ravandika_portofolio/ |
| `-Keisya` | Keisya's portfolio | `keisyazkafathaya2022/portofolio`, branch `main` | https://keisyazkafathaya2022.github.io/portofolio/ |

- Edit only the site named by the tag. Never change the other site's files in the same request.
- If a request has no tag and the target is not obvious, ask which site before editing.
- `keisya/` in this repository is the old copy of Keisya's site, kept as a backup. Do not edit it; Keisya's changes go to her own repository.
